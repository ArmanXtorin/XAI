# Xtorin AI Mobile v0.1

Native Android Kotlin application. Offline commands, local chat history, and key/value memory.

## Build
Open GitHub Actions > Build Android APK > Run workflow, or push to main.
Download the debug APK artifact after a successful build.

## Commands
help, time, date, remember favorite_game = Minecraft, recall favorite_game, memories, clear memory favorite_game

No internet permission or cloud AI in v0.1. The app is an offline command assistant, not yet a language model.
